# AtCoder-Ebbinghaus

AtCoderで解いた問題のうち、**エビングハウスの忘却曲線**に基づいて「1日以内 / 1週間以内 / 1ヶ月以内」に
**ACしていない問題（not AC）**を抽出して一覧表示するシンプルなWebアプリです。

- 解答履歴は [AtCoder Problems API](https://kenkoooo.com/atcoder/) を利用しています。
- 入力したAtCoder IDの提出履歴から、対象期間に**AC以外の結果**だった問題を抽出します。

## 使い方

1. `docs/index.html` をブラウザで開きます。
2. AtCoder ID を入力します。
3. 対象期間（1日 / 1週間 / 1ヶ月）を選択し、送信ボタンを押します。
4. 対象期間内に**ACしていない**問題が一覧表示されます。

## 仕組み（概要）

- `docs/app.js` がAtCoder Problems APIから提出履歴を取得します。
- 期間ごとに「AC以外」の提出を抽出し、問題一覧を作成します。
- 問題一覧は問題情報APIからタイトルを引いて表示します。

## 改善アイデア

- **期間指定の自由度**: 1日/1週間/1ヶ月以外の期間をカスタム指定できるようにする。
- **AC履歴との突合**: 対象期間内にnot ACでも、その後AC済みの問題を除外するオプションを追加する。
- **並び替え/フィルタ**: コンテスト名や難易度（推定レート）でソート・フィルタを可能にする。
- **状態の保存**: チェックボックスの状態や最後に入力したIDをLocalStorageに保存する。
- **UX改善**: ローディング表示、エラー表示（ID未入力/API失敗）などのユーザーフィードバックを追加する。
- **パフォーマンス**: APIの取得結果をキャッシュして、再検索時の待ち時間を短縮する。
